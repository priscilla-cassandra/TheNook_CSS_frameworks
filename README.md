# TheNook_CSS_frameworks
Course assignment for the CSS-frameworks class to display the use of CSS frameworks. 
The Nook is a social media app dedicated to anything related to books. 

# Built with
- HTML
- Tailwind CSS
- Vanilla JavaScript

# Setup
1. Getting started <br>
In the terminal, do the following:
   ```baSH
   git clone https://github.com/priscilla-cassandra/TheNook_CSS_frameworks.git
   ```

   ```bash
   git checkout css-frameworks
   ```

   ```bash
   npm install
   ```

# Running the project
Open index.html with the Live Server extension in VSCode (right-click on the file -> "Open with Live Server")

# Scripts
| Script                   | Description                                                                         |
| ------------------------ | ------------------------------------------------------------------------------------|
| `npm run dev`            | Tailwind stays running, and regenerate styles when changes are detected             |
| `npm run build`          | Generates the final tailwind CSS, writes it to css/style.css and minifies the output|
